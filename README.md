# 游戏手柄项目

> **项目状态**: **中期开发阶段** - 软件设计进行中

## 项目概述

一个基于STM32F103RCT6微控制器和AXP2101电源管理芯片的游戏手柄，旨在提供高精度模拟输入和可靠的无线控制体验，同时以项目为驱动，学习诸如 FreeRTOS 中的 IPC、tickless、无线通信协议、elog异步日志输出等等。

**注意**：本项目目前正在积极开发中。所有特性、规格和时间表都可能随着设计进展而调整。
